Öppen Plattform

Öppna plattformar för fastighetsdata

När en fastighet har system för energi, passage, ventilation och felanmälan från olika leverantörer behövs något som binder ihop dem. Plattformarna här samlar data från flera system på ett ställe och gör den tillgänglig via öppna gränssnitt.

Det här ska ni titta efter

Vilka system finns det färdiga kopplingar till?

Värdet av en plattform är kopplingarna. Begär listan över system som redan är integrerade och jämför den med det ni har i dag.

Öppet API och dataexport

Kontrollera att ni själva kan hämta ut data via API, utan att gå via leverantören för varje ny användning.

Vem driver plattformen efter installation?

Plattformar kräver förvaltning när nya system ansluts. Klargör vad som ingår i avgiften och vad som debiteras per timme.

Säkerhet i uppkopplade system

En plattform som når styrsystemen är också en angreppsyta. Fråga om segmentering, behörigheter och hur uppdateringar hanteras.

Vanliga frågor

Behöver vi en plattform om vi bara har några få system?+

Inte nödvändigtvis. Med två eller tre system räcker ofta direkta integrationer. En plattform lönar sig när antalet system och fastigheter växer.

Vad är ett "operativsystem för byggnader"?+

Det är ett annat namn på samma idé: ett gemensamt lager som samlar data från byggnadens tekniska system och gör den användbar för andra tillämpningar.

Hur hänger plattformar ihop med digitala tvillingar?+

En digital tvilling bygger ofta på samma datainsamling. Plattformen är grunden, tvillingen är en av sakerna man kan bygga ovanpå.
